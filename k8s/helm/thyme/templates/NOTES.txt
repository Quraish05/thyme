Thyme sandbox installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

1. Watch it come up (backend may restart a couple of times until Postgres is ready):
     kubectl -n {{ .Release.Namespace }} get pods -w

{{- if .Values.ingress.enabled }}
2. Add the Ingress host to /etc/hosts (once):
     echo "127.0.0.1 {{ .Values.ingress.host }}" | sudo tee -a /etc/hosts

3. Open the app:
     http://{{ .Values.ingress.host }}

   Or verify without editing /etc/hosts:
     curl --resolve {{ .Values.ingress.host }}:80:127.0.0.1 http://{{ .Values.ingress.host }}/api/v1/health
{{- else }}
2. Ingress is disabled. Reach the app via port-forward:
     kubectl -n {{ .Release.Namespace }} port-forward svc/frontend 3000:{{ .Values.frontend.port }}
{{- end }}

Reminder: images must be loaded into the cluster first —
  kind load docker-image {{ .Values.backend.image }} {{ .Values.frontend.image }} --name thyme
